# Contributing to Orbit Server

Thank you for wanting to help!

**Pull requests aren't being accepted yet.** There isn't enough maintainer time to review contributions properly. Contributions will open soon; this page will say so when they do.

## What helps right now
- **Bug reports.** Open an issue with the server version, how you run it (Docker, plain JVM) and what happened. Leave out tokens, keys, host names and any health data.
- **Ideas.** Tell us what you'd like your own Orbit Server to do.

## Security problems
Please don't open a public issue. See [SECURITY.md](SECURITY.md).
